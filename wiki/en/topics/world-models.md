## Overview

World models are learned simulators: models that let an agent predict how its environment will respond to its actions. Research on them asks how to learn such models from raw observations, how to use them to choose actions or to train policies, and how to stop agents from exploiting the model's mistakes. This topic page follows that line of work paper by paper.

## Timeline

- 2018: [World Models](../sources/2018-world-models.md) splits an agent into a large unsupervised world model and a tiny controller, and shows that a policy trained entirely inside the model's dream can work in the real game (p.7).

## Key concepts

- [World model](../concepts/world-model.md): a learned model that predicts how the environment changes.
- [Variational autoencoder](../concepts/variational-autoencoder.md): compresses observations into a small latent vector.
- [Mixture density RNN](../concepts/mixture-density-rnn.md): predicts a probability distribution over the next latent state.
- [Learning in imagination](../concepts/learning-in-imagination.md): training a policy on experience generated by the world model.

## Key terms

- **Latent vector**: a short list of numbers that summarizes an observation.
- **Rollout**: one run of an agent in an environment, from the start to the end of an episode.
- **Controller (policy)**: the part of an agent that chooses actions.
- **Model-based reinforcement learning**: reinforcement learning that learns or uses a model of the environment.
- **Model exploitation**: an agent finding behaviour that scores well only because the model is wrong.
- **Temperature**: a parameter that scales how random a model's samples are.

## Open questions

- How can an agent explore enough to improve its world model in environments that a random policy cannot cover? [World Models](../sources/2018-world-models.md) proposes an iterative procedure driven by curiosity but does not test it (pp.10-11).
- How can a policy trained in imagination avoid exploiting the model's errors? [World Models](../sources/2018-world-models.md) only partly addresses this with a stochastic model and a tunable temperature (p.10).
