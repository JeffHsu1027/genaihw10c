## Overview

World models are learned simulators: models that let an agent predict how its environment will respond to its actions. Research on them asks how to learn such models from raw observations, how to use them to choose actions or to train policies, and how to stop agents from exploiting the model's mistakes. This topic page follows that line of work paper by paper.

## Timeline

- 2018: [World Models](../sources/2018-world-models.md) splits an agent into a large unsupervised world model and a tiny controller, and shows that a policy trained entirely inside the model's dream can work in the real game (p.7).
- 2019: [PlaNet](../sources/2019-planet.md) learns a recurrent state-space model with deterministic and stochastic parts and plans every action online in latent space, reaching strong model-free performance with about 200 times fewer episodes (p.2).
- 2020: [Dreamer](../sources/2020-dreamer.md) keeps PlaNet's world model but learns behavior purely in imagination with an actor-critic whose value model looks beyond the horizon, beating PlaNet and the model-free D4PG on average across 20 tasks (p.6, Fig. 6).

## Key concepts

- [World model](../concepts/world-model.md): a learned model that predicts how the environment changes.
- [Model-based reinforcement learning](../concepts/model-based-reinforcement-learning.md): reinforcement learning that learns or uses such a model.
- [Variational autoencoder](../concepts/variational-autoencoder.md): compresses observations into a small latent vector.
- [Mixture density RNN](../concepts/mixture-density-rnn.md): predicts a probability distribution over the next latent state.
- [Recurrent state-space model](../concepts/recurrent-state-space-model.md): a latent dynamics model with a deterministic memory and a stochastic state.
- [Learning in imagination](../concepts/learning-in-imagination.md): training a policy on experience generated by the world model.
- [Latent space planning](../concepts/latent-space-planning.md): choosing actions by searching action sequences inside the model.
- [Latent overshooting](../concepts/latent-overshooting.md): training a latent model on multi-step predictions.
- [Actor-critic](../concepts/actor-critic.md): learning a policy together with a value function that estimates future rewards.

## Key terms

- **Latent vector**: a short list of numbers that summarizes an observation.
- **Rollout**: one run of an agent in an environment, from the start to the end of an episode.
- **Controller (policy)**: the part of an agent that chooses actions.
- **Model-based reinforcement learning**: reinforcement learning that learns or uses a model of the environment.
- **Model exploitation**: an agent finding behaviour that scores well only because the model is wrong.
- **Temperature**: a parameter that scales how random a model's samples are.
- **POMDP (partially observable Markov decision process)**: a decision problem in which the agent's observations do not reveal the full state.
- **Model-predictive control (MPC)**: re-planning after every new observation and executing only the first action of each plan.
- **Cross entropy method (CEM)**: a search method that repeatedly samples candidates, keeps the best ones, and refits the sampling distribution to them.
- **Action repeat**: executing each chosen action for several environment steps in a row.
- **Value function**: a prediction of how much future reward an agent will collect from a given state.
- **Imagination horizon**: how many steps ahead an agent rolls out its world model when imagining.
- **λ-return**: a value target that blends estimates which trust real or imagined rewards for different numbers of steps before relying on the value function.
- **Reparameterization**: writing a random sample as a fixed function of noise, so gradients can flow through the sampling step.

## Open questions

- How can an agent explore enough to improve its world model in environments that a random policy cannot cover? [World Models](../sources/2018-world-models.md) proposes an iterative procedure driven by curiosity but does not test it (pp.10-11).
- How can a policy trained in imagination avoid exploiting the model's errors? [World Models](../sources/2018-world-models.md) only partly addresses this with a stochastic model and a tunable temperature (p.10).
- How can a planning agent account for rewards beyond its planning horizon? [PlaNet](../sources/2019-planet.md) suggests learning a value function (p.8).

> **Superseded:** [Dreamer](../sources/2020-dreamer.md) answers this by learning a value model in imagination (p.4, Fig. 4).

- Which objective should a world model be trained with? [Dreamer](../sources/2020-dreamer.md) finds pixel reconstruction best and reward prediction alone insufficient, and expects better representation learning to be needed for visually complex environments (p.9).
- Can agents that learn purely through world models become competitive in discrete-action domains such as Atari? [Dreamer](../sources/2020-dreamer.md) learns successful behaviors there but is not yet competitive (p.16).
