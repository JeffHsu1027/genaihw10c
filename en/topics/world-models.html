Topic

World models

World models · 5 sources

Overview

World models are learned simulators: models that let an agent predict how its environment will respond to its actions. Research on them asks how to learn such models from raw observations, how to use them to choose actions or to train policies, and how to stop agents from exploiting the model's mistakes. This topic page follows that line of work paper by paper.

Timeline

  • 2018: World Models splits an agent into a large unsupervised world model and a tiny controller, and shows that a policy trained entirely inside the model's dream can work in the real game (p.7).
  • 2019: PlaNet learns a recurrent state-space model with deterministic and stochastic parts and plans every action online in latent space, reaching strong model-free performance with about 200 times fewer episodes (p.2).
  • 2020: Dreamer keeps PlaNet's world model but learns behavior purely in imagination with an actor-critic whose value model looks beyond the horizon, beating PlaNet and the model-free D4PG on average across 20 tasks (p.6, Fig. 6).
  • 2021: DreamerV2 switches to categorical latents and KL balancing and becomes the first agent to reach human-level Atari performance by learning purely inside a separately trained world model (p.1).
  • 2023: DreamerV3 adds robustness techniques so that one fixed configuration outperforms specialized methods on more than 150 tasks, and becomes the first algorithm to collect diamonds in Minecraft from scratch (p.1).

Key concepts

  • World model: a learned model that predicts how the environment changes.
  • Model-based reinforcement learning: reinforcement learning that learns or uses such a model.
  • Variational autoencoder: compresses observations into a small latent vector.
  • Mixture density RNN: predicts a probability distribution over the next latent state.
  • Recurrent state-space model: a latent dynamics model with a deterministic memory and a stochastic state.
  • Learning in imagination: training a policy on experience generated by the world model.
  • Latent space planning: choosing actions by searching action sequences inside the model.
  • Latent overshooting: training a latent model on multi-step predictions.
  • Actor-critic: learning a policy together with a value function that estimates future rewards.
  • Categorical latents: describing the latent state with discrete choices instead of Gaussians.
  • KL balancing: training the prior of a latent model faster than its posterior.
  • Symlog predictions: predicting targets of any scale by compressing them.
  • Return normalization: scaling returns so one exploration setting fits every environment.

Key terms

  • Latent vector: a short list of numbers that summarizes an observation.
  • Rollout: one run of an agent in an environment, from the start to the end of an episode.
  • Controller (policy): the part of an agent that chooses actions.
  • Model-based reinforcement learning: reinforcement learning that learns or uses a model of the environment.
  • Model exploitation: an agent finding behaviour that scores well only because the model is wrong.
  • Temperature: a parameter that scales how random a model's samples are.
  • POMDP (partially observable Markov decision process): a decision problem in which the agent's observations do not reveal the full state.
  • Model-predictive control (MPC): re-planning after every new observation and executing only the first action of each plan.
  • Cross entropy method (CEM): a search method that repeatedly samples candidates, keeps the best ones, and refits the sampling distribution to them.
  • Action repeat: executing each chosen action for several environment steps in a row.
  • Value function: a prediction of how much future reward an agent will collect from a given state.
  • Imagination horizon: how many steps ahead an agent rolls out its world model when imagining.
  • λ-return: a value target that blends estimates which trust real or imagined rewards for different numbers of steps before relying on the value function.
  • Reparameterization: writing a random sample as a fixed function of noise, so gradients can flow through the sampling step.
  • Straight-through estimator: a way to pass gradients through a discrete sample by treating the sampling step as if it were the identity in the backward pass.
  • Reinforce gradient: a policy gradient that increases the probability of sampled actions in proportion to how good they turned out; unbiased but noisy.
  • Sticky actions: an Atari evaluation setting in which the previous action is sometimes repeated at random, so agents cannot memorize exact action sequences.
  • Human-normalized score: a game score rescaled so that a reference human player, or the human world record, corresponds to one.
  • Fixed hyperparameters: using the same settings on every task instead of tuning them per domain.
  • Free bits: not penalizing a KL term while it is already below a small threshold.
  • Replay ratio: how many training steps an agent takes per step of new experience collected.
  • PPO: a widely used model-free policy gradient algorithm, often taken as a robust baseline.
  • Minecraft Diamond: a benchmark task in which an agent must collect a sequence of items in Minecraft, ending with a diamond, from sparse rewards.

Open questions

  • How can an agent explore enough to improve its world model in environments that a random policy cannot cover? World Models proposes an iterative procedure driven by curiosity but does not test it (pp.10-11).
  • How can a policy trained in imagination avoid exploiting the model's errors? World Models only partly addresses this with a stochastic model and a tunable temperature (p.10).
  • How can a planning agent account for rewards beyond its planning horizon? PlaNet suggests learning a value function (p.8).

Superseded: Dreamer answers this by learning a value model in imagination (p.4, Fig. 4).

  • Which objective should a world model be trained with? Dreamer finds pixel reconstruction best and reward prediction alone insufficient, and expects better representation learning to be needed for visually complex environments (p.9).
  • Can agents that learn purely through world models become competitive in discrete-action domains such as Atari? Dreamer learns successful behaviors there but is not yet competitive (p.16).

Superseded: DreamerV2 reaches human-level performance on 55 Atari games (p.7, Table 1).

  • Why do categorical latents work better than Gaussian ones? DreamerV2 only offers hypotheses (p.9).
  • How can a reconstruction-based world model capture small but important objects? DreamerV2 fails on Video Pinball, where the ball is a single pixel (p.8).
  • Can a world-model agent find diamonds in Minecraft reliably, not only occasionally? DreamerV3 gets one in 0.4% of episodes at its budget (p.24, Fig. 9).
  • Can world models be pretrained on unlabeled data such as internet videos, or shared across domains? DreamerV3 names these as future directions (p.11).
