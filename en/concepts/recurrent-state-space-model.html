Concept

Recurrent state-space model

RSSM · 2 sources

One-line definition

A latent dynamics model whose state has a deterministic part, carried forward by a recurrent network, and a stochastic part sampled at every step.

Explanation

A purely deterministic recurrent model remembers well but can only predict a single future. A purely stochastic state-space model can represent uncertainty but struggles to keep information across many steps. Combining both lets the deterministic path act as memory while the stochastic path represents what is uncertain about the next state. The model is usually trained like a sequential variational autoencoder, with an encoder that infers the latent state from observations.

Explainer: The deterministic part is a diary that faithfully keeps what has happened; the stochastic part is a guess about what might happen next.

What each source says

Learning Latent Dynamics for Planning from Pixels (2019)

PlaNet introduces the RSSM: an RNN updates the deterministic state from the previous deterministic state, stochastic state and action, the stochastic state is sampled from a Gaussian given the deterministic state, and observations and rewards are predicted from both (p.4, Eq. 4). All information about the observations must pass through the sampling step of the encoder, to avoid a deterministic shortcut from inputs to reconstructions (p.4). In the experiments, both paths are needed on every task, and without the stochastic part the agent does not learn at all (p.6, Fig. 4). The implementation uses a GRU with 200 units and a 30-dimensional stochastic state (p.12). Unlike a purely stochastic model, the RSSM is robust to the choice between ReLU and ELU activations (p.15, Fig. 9).

Dream to Control: Learning Behaviors by Latent Imagination (2020)

Dreamer implements its transition model as the RSSM of PlaNet, and builds the representation model by combining the RSSM with a CNN applied to the image (p.6). Its latent distributions are 30-dimensional diagonal Gaussians, as in PlaNet (p.14). Given only the actions after five context frames, the RSSM predicts 45 steps ahead accurately enough for Dreamer to learn behaviors in its latent space (p.5, Fig. 5).

Comparing the sources

  • PlaNet introduces the RSSM and uses it for planning (p.4).
  • Dreamer reuses it unchanged for policy learning (p.6). The same model therefore supports two different ways of choosing actions; Dreamer builds directly on PlaNet, and this summary is this Wiki's own.

Related concepts

  • World model: the RSSM is a design for the world model.
  • Variational autoencoder: the RSSM is trained like a sequential VAE.
  • Latent overshooting: an extra objective for training such models on multi-step predictions.
  • Mixture density RNN: another way to add randomness to a recurrent model; it samples the output, while the RSSM samples part of the state.
