Concept

World model

dynamics model, environment model, predictive model of the environment · 6 sources

One-line definition

A learned model of an environment that predicts what will happen next, usually given the current state and an action.

Explanation

An agent that can predict the consequences of its actions does not have to try everything in the real world. A world model learns those predictions from experience, often in a compressed latent space instead of raw pixels. It can be used in two main ways: as a source of features that summarize the present and hint at the future, or as a simulator in which an agent can practise. Because it is learned, it is never perfect, and an agent that relies on it can be misled by its errors.

Explainer: A world model is like the picture in a batter's head that tells them where a fastball will be before their eyes can follow it.

What each source says

World Models (2018)

World Models builds the world model from two parts: a VAE that compresses each frame and an MDN-RNN that predicts the next compressed frame (p.2, Fig. 4). The world model is trained without rewards, and only the small controller sees the reward (p.5). The paper uses the world model in both ways: its hidden state gives the controller a sense of the future in Car Racing (p.5), and in VizDoom it fully replaces the real game during training (p.7).

Learning Latent Dynamics for Planning from Pixels (2019)

PlaNet calls its world model a latent dynamics model: a transition model, an observation model, a reward model and an encoder, built as a recurrent state-space model (p.3). Because the model also predicts rewards, the planner can score action sequences purely in latent space without generating images (p.3). The model is trained on data that the agent keeps collecting by planning with the partially trained model, not only on random data (p.3).

Dream to Control: Learning Behaviors by Latent Imagination (2020)

Dreamer uses the same world model as PlaNet and describes it as summarizing the agent's experience so that complex behaviors can be learned from it (p.1). The world model predicts rewards from actions and past observations, and any learning objective for it can be combined with Dreamer (p.2). The paper compares three objectives for learning it: image reconstruction works best, contrastive estimation solves about half of the tasks, and reward prediction alone is not enough (p.8, Fig. 8).

Mastering Atari with Discrete World Models (2021)

DreamerV2 describes world models as summarizing an agent's experience into a predictive model that can replace the environment for learning behaviors (p.2). Its world model adds a discount predictor, so that imagined trajectories can account for episode ends, and uses categorical latents with KL balancing (pp.3-4). The world model has about 20 million parameters (p.4), and it is accurate enough for an agent that learns only inside it to reach human-level Atari performance (p.2). The world model relies on image gradients: without them performance collapses, while stopping reward gradients changes little (p.9).

Mastering Diverse Domains through World Models (2023)

DreamerV3 describes the world model as giving the agent rich perception and the ability to imagine the future, and notes that learning and using world models robustly had been an open problem (p.2). Its performance rests mainly on the unsupervised reconstruction loss of the world model rather than on reward and value gradients, which the authors see as an opening for pretraining on unsupervised data (p.10). Larger world models, from 12 million to 400 million parameters, both score higher and need less environment interaction (p.10, Fig. 6).

Training Agents Inside of Scalable World Models (2025)

Dreamer 4 describes world models as learning general knowledge from videos and simulating experience for training behaviors in imagination (p.1). It argues that earlier world-model agents were accurate only in narrow environments, while large controllable video models still missed precise object interactions and were too slow (p.2). Its transformer world model, with 2B parameters, runs in real time on one GPU (p.9). Players complete 14 of 16 Minecraft tasks inside it, compared with 5 of 16 for the large Oasis model (p.13). Its memory is still short and its inventory predictions imprecise (p.18).

Comparing the sources

  • Both learn a compressed latent state from pixels and a transition model over it: World Models with a VAE and an MDN-RNN (p.2, Fig. 4), PlaNet with a recurrent state-space model (p.4, Eq. 4).
  • World Models trains its model once on random-policy data, and in Car Racing the model never sees rewards (p.5).
  • PlaNet predicts rewards with the model and keeps retraining it on data collected by its own plans (p.3).
  • Both warn that a purely deterministic model is easy to exploit: World Models for its controller (p.9) and PlaNet for its planner (p.4, Fig. 2). This is agreement, not conflict.
  • Dreamer keeps PlaNet's world model and changes only how behavior is derived from it, which shows that the same model can serve planning or policy learning (p.8).
  • DreamerV2 keeps the same overall design but changes the latent variables and the KL term, which is enough to move from simple control tasks to human-level Atari (p.2).
  • DreamerV2 and DreamerV3 agree that image reconstruction, not reward prediction, is the main learning signal for the world model (p.10).
  • Dreamer 4 replaces the recurrent world model used from PlaNet to DreamerV3 with a transformer, because the recurrent design was efficient but hard to scale to diverse data (p.29).
  • PlaNet, Dreamer, DreamerV2, DreamerV3 and Dreamer 4 cite World Models (see their source pages); this side-by-side comparison is this Wiki's own summary.

Related concepts

  • Variational autoencoder: compresses observations for the world model.
  • Mixture density RNN: predicts the next state as a probability distribution.
  • Recurrent state-space model: a world model design with deterministic and stochastic state.
  • Categorical latents: discrete latent states used in DreamerV2's world model.
  • Shortcut forcing: the objective of Dreamer 4's transformer world model.
  • Action conditioning: making predictions depend on the agent's actions.
  • Model-based reinforcement learning: reinforcement learning that uses a world model.
  • Learning in imagination: training an agent inside a world model.
