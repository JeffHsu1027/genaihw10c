# /make-slides：從 Wiki 產生教學簡報

規格與理由見 `docs/slides-plan.md`（以下簡稱 PLAN）。本檔是執行步驟。所有路徑相對於專案根目錄。

## 0. 開始前

1. 執行 `python scripts/check.py`，必須全部通過（PLAN 第 1 節）。不通過就停下，回報擁有者。
2. 工作目錄 `decks/world-models/`，狀態全部存成檔案：`sources.md`、`cards/`、`outline.md`、`drafts/`、`deck.html`、`deck.css`、`report.md`。
3. 關卡腳本：`python .claude/skills/make-slides/gates.py <g1|g2|g4|render>`。腳本只讀檔與回報，不修改成品（`render` 除外，它只負責把逐頁稿轉成 HTML）。

## 1. 共同規則（每個節點都適用）

- **只能讀 Wiki**：`wiki/zh/`、`wiki/en/` 的 Markdown。不可上網、不可讀 `raw/` 的 PDF、不可用自己的印象補內容。Wiki 沒有的就停下，記進 `report.md`，退回階段 1（依 `AGENTS.md` 7.1 補頁面）。
- **每個節點只看 PLAN 第 4 節允許的輸入**，只寫自己的輸出檔。
- **出處**：每個事實都連到同名的中文 Wiki HTML 頁。從 `decks/world-models/` 出發的路徑是 `../../zh/<sources|concepts|topics>/<slug>.html`（逐頁稿與證據卡都用這個路徑）。論文主張保留 Wiki 上的頁碼 `(p.7)`、`(p.7, Fig. 3)`。概念頁的通用定義不需要頁碼，但要連到概念頁。
- **比喻與過場**：可以新寫，但不可含數字或論文主張；以 `> 比喻：` 或 `> 過場：` 開頭，與事實分開。
- **術語**：第一次出現寫「中文（English）」並用一句話解釋；讀者懂 AI／神經網路，但沒聽過世界模型與強化學習。
- **report.md**：每次跑關卡都新增一筆（格式見第 4 節），通過或退回都要記。
- **剎車**：同一關退回滿 3 次就停下，交給擁有者決定。每一輪只修報告列出的問題，不順手改別處。
- **commit**：每過一關，依 `AGENTS.md` 7.6 自動 commit（訊息 `slides: <關卡> 通過（第 N 輪）`），不 push。

## 2. 節點

### 節點 1 檢索 → `sources.md`

- 只讀：`wiki/zh/index.md`、`wiki/zh/topics/world-models.md`（需要時對照英文版）。
- 寫：相關來源清單（slug、標題、年份、為什麼和「世界模型是什麼」有關、預計在哪段教學用到），以及會用到的概念頁清單。
- 關卡 **G1**：`gates.py g1`。主題頁與 `sources.md` 的相關來源都要 ≥3 篇且頁面存在；不通過就停下，回報缺什麼。

### 節點 2 證據卡 → `cards/<source-slug>.md`

- 一篇來源一張卡。只讀該來源的中文 Wiki 頁與它連到的概念頁；不可混入其他來源頁的內容。
- 每個主張一個 `## C<n>` 小節，固定三行：

  ```
  ## C1
  - 主張：<用自己的話改寫，給簡報用>
  - 出處：[<頁面標題>](../../zh/sources/<slug>.html) (p.7)
  - Wiki 原文：「<從該 Wiki 頁 Markdown 逐字複製的一段，可省略連結語法>」
  ```

  `出處` 指向概念頁時可以沒有頁碼（通用定義）；指向來源頁時一定要有頁碼。主張的數字必須出現在 Wiki 原文中。
- 關卡 **G2**：`gates.py g2`。檢查每個主張的連結存在、頁碼格式正確且不超過來源頁的 `pages`、Wiki 原文逐字出現在該頁、頁碼出現在原文所在段落、主張中的數字都出現在原文。不合格只重做該張卡。

### 節點 3 大綱 → `outline.md`

- 只讀：`sources.md` 與所有證據卡。不可加入卡片以外的主張。
- 寫：教學順序（建議：動機 → 核心概念 → 發展脈絡 → 比較 → 限制 → 總結）、8–15 頁的每頁標題、每頁要講的重點與使用的卡片編號（例 `2019-planet#C3`）。
- **人工關卡**：停下來請擁有者確認大綱。退回時修大綱，或回到節點 1 補檢索。擁有者同意前不可進入節點 4。

### 節點 4 逐頁稿 → `drafts/<nn>.md`

- 只讀：`outline.md` 與該頁列出的卡片。不可引用卡片以外的內容。
- 每頁一個檔（`01.md`…），格式：

  ```
  ---
  slide: 1
  title: 世界模型是什麼？
  cards: [2018-world-models#C1]
  ---
  - 重點一句話，句尾標出處 [World Models](../../zh/sources/2018-world-models.html) (p.1)
  > 比喻：……
  ```

  每頁最多 6 個項目、每個項目最多約 60 個中文字（G4 會量測實際是否溢出）。
- 內圈 loop（最多 2 輪）：寫 → 對照卡片查出處 → 修。
- 關卡 **G3 忠實度**：開一個**全新的子代理（新對話）**，只給它 `drafts/` 與 `cards/`（與 `outline.md` 用來確認覆蓋），不給本對話的脈絡。它逐頁回報：主張是否忠於卡片、有沒有講反、數字與頁碼是否一致、比喻是否扭曲原意、大綱列的重點是否都有涵蓋。審查報告原文記進 `report.md`。某頁有錯 → 只退回該頁；證據卡本身錯 → 退回節點 2 重做該卡（並重跑 G2）。

### 節點 5 渲染 → `deck.html`

- 只讀已通過 G3 的逐頁稿。`gates.py render` 把逐頁稿機械地轉成 `deck.html`（並複製 `deck.css`），**不改任何一個字**。版面問題只改 `.claude/skills/make-slides/deck.css`。
- 內圈 loop：render → 用 `.claude/launch.json` 的 `site` 開預覽 → 截圖 → 修 CSS → 再截圖。
- 關卡 **G4 渲染**：
  1. `gates.py g4`：頁數 8–15、所有站內連結檔案存在、每個含數字的項目都有出處連結。
  2. 在瀏覽器開 `http://localhost:8000/decks/world-models/deck.html`，執行 `.claude/skills/make-slides/g4_overflow.js` 的內容，回報每頁是否溢出；並截圖抽看。
  - 字太多 → 退回節點 4 縮短該頁，不准在節點 5 硬塞（不可縮小字級來塞字）。

### 節點 6 交件

- `deck.html`、`deck.css`、`report.md` 定稿；`report.md` 最後寫總結：每關跑了幾輪、退回了哪些地方、哪些檢查該往前移（反思素材）。

## 3. 退回規則（錯在哪一關就退回哪一關）

| 發現的問題 | 退回到 |
|---|---|
| 相關來源不足 | 停下（G1），回報缺什麼 |
| 證據卡出處或原文不符 | 節點 2，只重做該卡 |
| 大綱缺主題、擁有者退回 | 節點 3；缺資料則節點 1 |
| 某頁講錯、講反 | 節點 4，只修該頁 |
| 證據卡本身理解錯 | 節點 2 重做該卡，再重跑 G2 與受影響頁的 G3 |
| 字太多、溢出 | 節點 4 縮短該頁 |
| Wiki 沒有需要的內容 | 階段 1：依 `AGENTS.md` 7.1 補頁面，`check.py` 通過後再回來 |

## 4. report.md 紀錄格式

```
## [YYYY-MM-DD] <關卡> 第 <N> 輪：通過｜退回
- 檢查方式：<腳本指令或審查方式>
- 結果：<腳本輸出摘要或審查結論>
- 問題：<逐項>（沒有就寫「無」）
- 退回：<節點與檔案>（通過就寫「無」）
```
