這份文件存放「以 Wiki 產生教學 HTML 簡報」的所有規則。它不屬於 LLM Wiki 的日常規則（`AGENTS.md`），**建 Wiki 期間不使用**。

- 建立日期：2026-11-24（由 `AGENTS.md` 移出，見 `docs/requirements.md` P23）；同日依第 10 週講義〈把你的工作拆成 AI 能做的流程〉補上 loop / graph 的設計規格（第 4、5 節）。
- 執行時機：通過第 1 節的開始條件之後，由擁有者明確下指令才開始。
- 執行時的第一步：依本文件撰寫 `.claude/skills/make-slides/SKILL.md`（以 `/make-slides` 呼叫，相當於講義中放在 `.agents/workflows/` 的 workflow 檔）與關卡腳本（DEC D8、§8 階段 2）。在那之前不建立 skill，避免建 Wiki 時被誤用。
- 背景與理由：`docs/decisions.md`（以下簡稱 DEC）D7、§6.2、§7、§8；第 10 週講義（以下簡稱「講義」）。

## 2. 簡報規格

| 項目 | 規定 | 依據 |
|---|---|---|
| 主題 | 世界模型是什麼？（What is a World Model?） | DEC §1 |
| 讀者 | 知道 AI／神經網路是什麼，但沒聽過「世界模型」與強化學習的人；術語第一次出現都要解釋 | requirements N1 |
| 教學結構 | 有清楚的教學順序（例：動機 → 核心概念 → 發展脈絡 → 比較 → 限制 → 總結），在大綱關卡由擁有者確認 | 作業評分 9–10 分條件 |
| 語言 | 只做繁體中文；術語寫成「中文（English）」 | N7 |
| 頁數 | 8–15 頁 | DEC §6.2 G4、講義 |
| 知識來源 | **只能讀 Wiki**，不可搜尋網路、不可讀 PDF；外部資料必須先寫進 Wiki 才能用 | DEC D7 |
| 出處 | 每個事實標註 Wiki 出處頁面（超連結到同名的中文 Wiki HTML 頁）；論文主張保留 Wiki 上的頁碼格式 `(p.7)`、`(p.7, Fig. 3)` | DEC D7、N3、N7 |
| 比喻與過場 | 可以新寫教學用的比喻或過場，但不可含數字或論文主張；忠實度檢查只確認沒有扭曲原意 | DEC D7 |
| 輸出 | `decks/world-models/deck.html`（純靜態，可由 GitHub Pages 開啟）與 `report.md` | DEC §7 |

## 3. 流程（graph）

```
[0 主題＋讀者] → [1 檢索 Wiki：讀 topics/world-models 與 index]
                          ↓
                    ◆G1 覆蓋率關卡（腳本）
                       └ 相關來源 <3 → 停下，回報缺什麼
                          ↓
              [2 證據卡] 一篇一張，只能讀該篇的 Wiki 頁
                          ↓
                    ◆G2 出處檢查（腳本）
                       └ 不合格 → 只重做該張卡
                          ↓
              [3 大綱] → 👤 擁有者確認
                       └ 退回 → 修大綱，或回到 1 補檢索
                          ↓
              [4 逐頁稿]（內圈 loop：寫 → 查出處 → 修，最多 2 輪）
                          ↓
                    ◆G3 忠實度審查（新對話，只給逐頁稿與證據卡）
                       ├ 某頁有錯 → 只退回該頁
                       └ 證據卡本身錯 → 退回 2 重做該卡
                          ↓
              [5 渲染 HTML]（內圈 loop：產生 → 截圖 → 修版 → 再截圖）
                          ↓
                    ◆G4 渲染檢查（腳本＋截圖）
                       └ 字太多 → 退回 4 縮短，不准在 5 硬塞
                          ↓
              [6 交件：deck.html + report.md]
```

graph 決定大流程，loop 負責每一格裡的反覆修正（講義）。

### 關卡

| 關卡 | 方式 | 通過條件 |
|---|---|---|
| G1 覆蓋率 | 腳本 | 主題下 ≥3 篇來源，否則停下並回報缺什麼 |
| G2 出處 | 腳本 | 每張證據卡的每個主張都有 Wiki 頁面連結與 `(p.X)`，且該頁確實有這段內容 |
| 人工 | 擁有者 | 確認大綱（含教學結構） |
| G3 忠實度 | AI 審查，**開新對話，只給成品和來源** | 主張忠於 Wiki、沒有講反、比喻沒有扭曲原意、大綱列的重點都有涵蓋 |
| G4 渲染 | 腳本＋截圖 | 頁數 8–15、沒有文字溢出、所有出處連結有效 |

程式能檢查的（有沒有出處、連結斷了沒、頁數、溢出）一律寫成腳本；只有忠實度與講反這類判斷交給 AI 審查。「說檢查一下不算驗證」，關卡的結果以腳本輸出或審查報告為準。

## 4. 每個節點只能看什麼、改什麼（講義）

| 節點 | 輸入（只能看） | 輸出檔 | 不能做 |
|---|---|---|---|
| 1 檢索 | `wiki/en/index.md`、`topics/world-models.md` | `sources.md`（相關來源與理由） | 讀 PDF、上網 |
| 2 證據卡 | 一篇來源的 Wiki 頁（含它連到的概念頁） | `cards/<slug>.md` | 混入其他來源 |
| 3 大綱 | `sources.md`、所有證據卡 | `outline.md` | 加入卡片以外的主張 |
| 4 逐頁稿 | `outline.md`＋該頁對應的卡 | `drafts/<nn>.md` | 引用卡片以外的內容；排版時想順就改句子 |
| 5 渲染 | 已通過 G3 的逐頁稿 | `deck.html` | 改任何一個字（字太多要退回 4） |
| 檢查關卡 | 成品＋來源 | `report.md` 的一筆 | 自動修改成品 |

## 5. Loop 規格（每個 loop 寫清楚五件事＋剎車）

| 項目 | 內容 |
|---|---|
| 🎯 目標 | 只用 Wiki，產出 8–15 頁的教學 HTML 簡報 |
| 🚧 限制 | 第 4 節的「只能看、不能做」；不可上網、不可讀 PDF；不在簡報裡補 Wiki 沒有的內容 |
| ✅ 完成標準 | G1–G4 全過，擁有者確認過大綱 |
| 🛑 停止條件 | 全部通過；或同一關退回滿 3 次；或 G1 相關來源 <3（一開始就停）；資料不足就停，不硬湊知識 |
| ⏰ 觸發 | 擁有者下指令 `/make-slides`，且第 1 節開始條件成立 |

- **每一輪只修檢查報告列出的問題**，不順手改其他地方。
- **錯在哪一關就退回哪一關**：某頁講錯 → 只修那頁，其他頁不動；證據卡本身錯 → 退回重做那張卡；字太多 → 退回逐頁稿縮短；看大綱時發現缺主題 → 退回檢索補資料；Wiki 沒有 → 退回階段 1（見第 6 節）。
- **大圈要少、小圈要快**：錯誤要在離源頭最近的地方被抓到。如果常常從後面的關卡大圈退回，代表檢查該往前移；把移動的位置與理由寫進 `report.md` 與反思（作業步驟四）。
- **剎車**：每個關卡最多退回 3 次，超過就停下交給擁有者決定；loop 很花 token，不讓它無人看管地一直跑。

## 6. 執行規則

- **狀態都是檔案**：`decks/world-models/` 下有 `sources.md`、`cards/`、`outline.md`、`drafts/`、`deck.html`、`report.md`。每一關的產出都能打開看、放進 git、單獨重跑。
- **`report.md` 每次檢查都記一筆**：哪一關、第幾輪、結果、什麼錯、退回哪裡。這是執行紀錄（繳交第 5 項）與反思（第 6 項）的資料來源。
- **每過一關 commit 一次**：依 `AGENTS.md` 7.6，關卡通過後 AI 自動 commit（訊息寫明關卡與輪次），不 push。commit 歷史是執行紀錄的佐證。（取代 DEC D11，見 `docs/requirements.md` P26。）
- **跨階段退回**：Wiki 缺內容時，退回依 `AGENTS.md` 7.1 補 ingest 或補頁面，不在簡報裡補；補完 `check.py` 通過後再回來，並在 `report.md` 記一筆。
- **可選的對照組**：正式跑 graph 前，可先用講義的「Prompt 一句話」做一次（根據 Wiki 做一份世界模型的 HTML 簡報），記下它出了哪些錯，作為為什麼需要 graph 的證據。是否要做由擁有者決定。
- 所有路徑相對於專案根目錄，不寫本機絕對路徑。
