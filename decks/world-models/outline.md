# 節點 3 大綱：世界模型是什麼？

- 讀者：懂 AI／神經網路，但沒聽過世界模型與強化學習。
- 只讀：`sources.md` 與 `cards/` 的 7 張證據卡；每頁列出會用到的卡片編號，逐頁稿不可超出這些卡片。
- 教學結構：**動機 → 核心概念 → 第一個完整例子 → 發展脈絡（規劃 → 想像中學習 → 通用化 → 離線 → 給人用）→ 比較 → 限制 → 總結**。
- 頁數：14 頁（規格 8–15）。
- 主線：世界模型就是「學出來的模擬器」；同一個想法從 2018 到 2025，模型越來越強，用法也越來越廣。
